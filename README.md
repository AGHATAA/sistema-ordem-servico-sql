# Sistema de Ordem de Serviço - SQL Server

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de simular um sistema de gerenciamento de ordens de serviço utilizando SQL Server.

O sistema permite o cadastro de clientes, técnicos e serviços, além do controle de ordens de serviço e geração de consultas analíticas.

---

## 🛠️ Tecnologias Utilizadas

* SQL Server
* T-SQL
* Git
* GitHub

## ⚙️ Funcionalidades

* Cadastro de clientes
* Cadastro de técnicos
* Cadastro de serviços
* Controle de ordens de serviço
* Atualização de status
* Consultas analíticas
* Relatórios com Views
* Stored Procedure para atualização de status

---

## 🗄️ Estrutura do Banco de Dados

O banco possui as seguintes entidades:

* CLIENTE
* TECNICO
* SERVICO
* ORDEM_SERVICO

Com relacionamentos utilizando chaves estrangeiras.
